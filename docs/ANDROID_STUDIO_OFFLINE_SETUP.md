## Reproduce on the company computer

Git transfers the project and handoff, not the home machine's caches, SDK, JDK or init script. First install the same compatible runtime/toolchains and SDK components using that computer's persistent user directories, select them in Studio, then resolve online before expecting offline operation. Do not copy arbitrary artifacts into Gradle internals. Direct Google Maven may work on the company network; only use equivalent user routing if it is needed there.

The nonsecret routing portion of this machine's user init script is reproduced below for review. Place it under the **user** Gradle home `init.d/` on a machine requiring the same mirror; keep it out of project settings. It scopes both plugin-management and dependency repositories to this project, preserves coordinates and existing fallbacks, and is inherited by Studio:

```groovy
settingsEvaluated { settings ->
    if (settings.rootProject.name != 'CarObd' ||
        !new File(settings.settingsDir, 'core/model').isDirectory()) return
    [settings.pluginManagement.repositories,
     settings.dependencyResolutionManagement.repositories].each { repositories ->
        def mirror = repositories.maven {
            name = 'CarObdLocalGoogleMirror'
            url = uri('https://maven.aliyun.com/repository/google')
            content {
                includeGroupByRegex('com\\.android.*')
                includeGroupByRegex('com\\.google.*')
                includeGroupByRegex('androidx.*')
            }
        }
        repositories.remove(mirror)
        repositories.addFirst(mirror)
    }
}
```

The optional `carobdWarmAllConfigurations` maintenance task above is supplied by the home user's init script, not the project. On a new machine that task must also be installed or its equivalent used; an unknown-task error does not mean project Gradle is broken. Normal builds/Sync never depend on this maintenance task. Do not copy the home user's proxy/account credentials. Configure any company-required network access separately.

To reproduce the explicit maintenance task on another machine, append the following nonsecret task to the same user-level script. This is the exact task exercised on the home machine, not a project build requirement:

```groovy
gradle.projectsEvaluated {
    if (gradle.rootProject.name != 'CarObd' || !gradle.startParameter.projectProperties.containsKey('carobdCacheWarmup')) return
    gradle.rootProject.tasks.register('carobdWarmAllConfigurations') {
        doLast {
            println('CAROBD_GRADLE_USER_HOME=' + gradle.gradleUserHomeDir)
            println('CAROBD_GRADLE_JAVA_HOME=' + System.getProperty('java.home'))
            def failures = []
            def configs = 0
            def artifacts = 0
            def metadataOnly = 0
            gradle.rootProject.allprojects.each { p ->
                (p.configurations.toList() + p.buildscript.configurations.toList()).findAll { it.canBeResolved }.each { c ->
                    if (c.name.endsWith('DependenciesMetadata')) {
                        metadataOnly++
                        println('METADATA_BUCKET ' + p.path + ':' + c.name + ' (resolved through real variant classpaths/BOM)')
                        return
                    }
                    configs++
                    try {
                        def view = c.incoming.artifactView {
                            lenient = true
                            // Project outputs are generated by build tasks, not external cache artifacts.
                            componentFilter { !(it instanceof org.gradle.api.artifacts.component.ProjectComponentIdentifier) }
                        }.artifacts
                        artifacts += view.artifacts.size()
                        view.failures.each { failures.add(p.path + ':' + c.name + ': ' + it.message) }
                        println('RESOLVED ' + p.path + ':' + c.name + ' artifacts=' + view.artifacts.size())
                    } catch (Exception e) { failures.add(p.path + ':' + c.name + ': ' + e.message) }
                }
            }
            println('CAROBD_CONFIGURATIONS=' + configs + ' ARTIFACT_OCCURRENCES=' + artifacts + ' METADATA_BUCKETS=' + metadataOnly + ' FAILURES=' + failures.size())
            failures.each { println('CAROBD_MISSING ' + it) }
            if (!failures.isEmpty()) throw new GradleException('Unresolved configurations: ' + failures.size())
        }
    }
}
```
